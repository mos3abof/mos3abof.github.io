{#- image: one or more images with an optional caption. Usage: {{ }} {{ }} {{ }} Parameters: src (string) Path to a single image. srcs (array, optional) Paths to multiple images displayed in a flex row, sharing the same caption. Can be combined with src. alt (string, optional) HTML alt attribute. Defaults to text. text (string, optional) Caption text rendered below the image(s). dir (string, optional) Caption text direction: "ltr" or "rtl". Defaults to the current page language. align (string, optional) Figure alignment: "left" | "center" | "right" (aliases: "start" | "end"). Defaults to "center". Uses logical CSS properties, so start/end are RTL-aware. size (string, optional) Max-width of the figure: "sm" | "md" | "lg" | "xl" | "2xl" | "full". Defaults to "md". link (string, optional) Wraps the image(s) in an anchor pointing to this URL. Opens in a new tab. Its output has no blank lines: Markdown would end the figure at one. -#} {%- component image(src: string = "", srcs: array = [], alt: string = "", text: string = "", dir: string = "", align: string = "center", size: string = "md", link: string = "", @lang: string) -%} {%- set images = [src, ...srcs] if src else srcs -%} {%- set resolved_alt = alt or text -%} {#- Caption direction: explicit dir param → page language -#} {%- set caption_dir = dir if dir else ("rtl" if lang == "ar" else "ltr") -%} {#- Alignment logical properties so left/right work in RTL too -#} {%- if align == "left" or align == "start" -%} {%- set align_class = "me-auto" -%} {%- elif align == "right" or align == "end" -%} {%- set align_class = "ms-auto" -%} {%- else -%} {%- set align_class = "mx-auto" -%} {%- endif -%} {#- Max-width of the figure -#} {%- if size == "sm" %}{% set size_class = "max-w-sm" %} {%- elif size == "md" %}{% set size_class = "max-w-md" %} {%- elif size == "lg" %}{% set size_class = "max-w-lg" %} {%- elif size == "xl" %}{% set size_class = "max-w-xl" %} {%- elif size == "2xl" %}{% set size_class = "max-w-2xl" %} {%- else %}{% set size_class = "w-full" %} {%- endif -%} {%- if images -%} {%- endif -%} {%- endcomponent image -%}
