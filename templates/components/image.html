{#- image: one or more images with an optional caption. Usage: {{ }} {{ }} {{ }} Parameters: src (string) Path to a single image. srcs (array, optional) Paths to multiple images displayed in a flex row, sharing the same caption. Can be combined with src. alt (string, optional) HTML alt attribute. Defaults to text. text (string, optional) Caption text rendered below the image(s). dir (string, optional) Caption text direction: "ltr" or "rtl". Defaults to the current page language. align (string, optional) Figure alignment: "left" | "center" | "right" (aliases: "start" | "end"). Defaults to "center". Uses logical CSS properties, so start/end are RTL-aware. size (string, optional) Max-width of the figure: "sm" | "md" | "lg" | "xl" | "2xl" | "full". Defaults to "md". link (string, optional) Wraps the image(s) in an anchor pointing to this URL. Opens in a new tab. crop (bool, optional) With srcs: crop the images to the same height (true, the default), or show each one whole, sized by its aspect ratio to share one height. Styled in css/components.css. Its output has no blank lines: Markdown would end the figure at one. -#} {%- component image(src: string = "", srcs: array = [], alt: string = "", text: string = "", dir: string = "", align: string = "center", size: string = "md", link: string = "", crop: bool = true, @page: map = {}, @lang: string) -%} {%- set images = [src, ...srcs] if src else srcs -%} {%- set resolved_alt = alt or text -%} {#- Caption direction: explicit dir param → page language -#} {%- set caption_dir = dir if dir else ("rtl" if lang == "ar" else "ltr") -%} {#- Alignment: left/right are the start/end of the line, so they mirror in RTL -#} {%- if align == "left" or align == "start" %}{% set align = "start" %} {%- elif align == "right" or align == "end" %}{% set align = "end" %} {%- else %}{% set align = "center" %}{% endif -%} {#- Max-width of the figure; anything else is the full width -#} {%- if size not in ["sm", "md", "lg", "xl", "2xl"] %}{% set size = "full" %}{% endif -%} {%- if images -%} {%- endif -%} {%- endcomponent image -%}
