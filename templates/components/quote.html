{#- quote: styled block quote with an optional attribution line. (Replaces the theme's quote component, which takes name and role.) Usage: {% %}Quote text.{% %} {% %}النص.{% %} Parameters: author (string, optional) Attribution shown below the quote after an em dash. dir (string, optional) Text direction: "ltr" or "rtl". Defaults to the current page language. Use dir="ltr" to force LTR inside an Arabic page, e.g. for English quotes embedded in Arabic posts. size (string, optional) Tailwind text-size suffix for the quote body, e.g. "xl" (default), "2xl", "lg". font (string, optional) Additional CSS class applied to the quote body, e.g. a font utility class like "amiri" or "scheherazade-new". Body: The quoted text. Line breaks are kept. -#} {%- component quote(author: string = "", dir: string = "", size: string = "", font: string = "", @lang: string) -%} {%- set quote_dir = dir if dir else ("rtl" if lang == "ar" else "ltr") -%} {%- endcomponent quote -%}
