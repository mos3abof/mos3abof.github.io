A Docusaurus 3 theme that brings the [Arabesque design system](@/projects/arabesque-design-system/index.md)
to documentation sites: its tokens, typography, components and code highlighting,
working in left-to-right and right-to-left alike. It ships with a documentation
site that uses the theme and explains how to set it up and customise it.
